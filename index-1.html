FREQUENTLY ASKED

How accurate is the VERITAS AI detection system?▼

VERITAS AI achieves 98.7% accuracy across controlled studies, combining facial micro-expression analysis, voice stress detection, and NLP behavioral profiling. Accuracy improves with multi-modal input (webcam + microphone + text).

Is my investigation data secure and private?▼

All data is encrypted using AES-256 with zero-knowledge architecture. We never access your investigation files. Data is stored locally by default with optional encrypted cloud backup.

Can VERITAS AI work without a webcam?▼

Yes. The system operates in text-only, audio-only, or full multi-modal modes. While accuracy peaks with webcam and microphone input, text and voice-only analysis still achieves over 89% detection accuracy.

What languages does the system support?▼

VERITAS AI supports 94 languages for NLP analysis. Voice stress analysis is language-agnostic. Facial recognition works universally. The UI is available in 12 languages.

Can I export investigation reports?▼

Reports can be exported as encrypted PDF, CSV data exports, or JSON for API integration. All exports are watermarked and include chain-of-custody metadata for legal admissibility.
